# Contributing to ElSi

Thanks for helping out!

1. Fork the repo and create a branch from `main`.
2. Keep changes focused; add or update tests where it makes sense.
3. Never commit secrets, API keys, or server addresses. Use `.env` files (git-ignored) and update `deploy/.env.example` for new settings.
4. Open a pull request describing what changed and why.

By contributing, you agree that your contributions are licensed under the MIT License.
